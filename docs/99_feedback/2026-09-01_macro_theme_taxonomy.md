## 1. メモの要旨

### 1.1 方法論

企業開示からボトムアップでカテゴリを作るのではなく、**日本銀行「経済・物価情勢の展望（展望レポート）」の2022年以降のBOX分析をトップダウンの参照源**として用いる。

2022年以降は日本経済がデフレ的環境からインフレ・賃金上昇を伴う環境へ移行した局面であり、国際商品市況・輸入物価・為替・価格転嫁・労働需給・賃金・サービス価格・金融環境・通商政策・AI/IT需要といった論点が繰り返し分析されている。展望レポートのBOXは、企業経営に影響する主要マクロテーマの**網羅性・粒度を検証する材料**になる。

BOXの論点は概ね次のように推移している。

```
2022  輸入インフレ・供給制約・円安
2023  価格転嫁・労働需給・賃金
2024  賃金と物価の循環・サービス価格・金融正常化
2025  人手不足・省人化投資・生産性・通商政策
2026  中東・原油・AI需要・関税・金利
```

日本銀行の分類をそのまま採用するのではなく、展望レポートで網羅性を確認し、適時開示で実務上の分類可能性を確認する、という双方向のサイクルで継続改善する。

### 1.2 設計思想

マクロテーマは原則として**「企業の外部で何が起きたか」**を表す。以下の階層を混同しない。

```
マクロテーマ → 波及経路 → 企業への影響 → 企業アクション
```

例：

```
中東情勢悪化 → 原油価格上昇 → 輸入物価上昇 → 原材料コスト上昇 → 値上げ
[マクロテーマ] [商品市況]    [波及経路]    [企業への影響]   [企業アクション]
```

### 1.3 分類体系（16）

| # | テーマ | 主な内容 |
|---|---|---|
| 1 | 商品市況・資源価格 | 原油、天然ガス、石油化学原料、穀物・食品原料、金属 |
| 2 | 輸入物価 | エネルギー／食品／中間財の輸入価格。商品市況の日本への伝達段階 |
| 3 | 為替 | 円安・円高、通貨ペア |
| 4 | 物価・価格形成 | 価格転嫁、サービス価格、消費者物価、企業の価格設定行動 |
| 5 | 労働市場 | 人手不足、賃金上昇、最低賃金、春闘 |
| 6 | 需要環境 | 国内・海外・輸出・インバウンド・設備投資需要 |
| 7 | 消費・家計 | 実質所得、節約志向、消費マインド、需要シフト |
| 8 | 金融環境 | 政策金利、市場金利、貸出金利、信用環境、イールドカーブ |
| 9 | 通商政策 | 関税、輸出入規制、経済制裁 |
| 10 | 地政学 | 中東、ロシア・ウクライナ、米中、台湾海峡 |
| 11 | サプライチェーン | 物流混乱、生産停止、部材不足、調達制約 |
| 12 | 業界需給 | 供給過剰・不足、在庫調整、生産能力、市況 |
| 13 | 技術・投資サイクル | AI需要、半導体サイクル、データセンター投資、IT投資 |
| 14 | 規制・制度 | 環境規制、税制、補助金、業法改正、脱炭素 |
| 15 | 資産価格 | 不動産価格、地価、株価 |
| 16 | 天候・自然災害 | 猛暑、寒波、台風、洪水、地震、干ばつ |

### 1.4 分類増殖を避ける方針

`中国需要` `自動車需要` などを個別テーマにせず、次元の組み合わせで表現する。

```
macro_theme = 需要環境 / region = 中国 / end_market = 自動車 / direction = 弱含み
```

### 1.5 他次元との役割分担（メモの提案）

- `dim_macro_theme` — 外部で何が起きたか
- `dim_transmission_mechanism`（**新設候補**）— マクロ変化が企業へ届くまでの波及経路
- `dim_impact_mechanism`（**復活提案**）— 対象企業に何が起きたか
- `dim_company_action` — 企業が何をしたか

### 1.6 メモ自身が挙げる未決論点

- 商品市況と輸入物価を分けるか（分離案を推奨）
- 物価・価格形成を macro_theme に置くか（レビュー対象）
- transmission_mechanism を独立次元にするか（有力な追加候補）
- 需要環境をどこまで細分化するか（組み合わせ表現を基本とする）

### 1.7 運用方針

未分類イベント発生率、`other` の増加、類似カテゴリ間の判定揺れ、L1/L2粒度の過不足、日銀BOXの新規テーマ、利用頻度、Human Review の修正傾向を定期レビューする。taxonomy に version を持たせ、過去データの再分類を可能にする。

## 2. レビュー

### 2.1 評価する点

- **日銀BOXをトップダウンの参照源にする方法論。** 恣意的なカテゴリ作りを避け、テーマ拡張のたびに立ち返れる基準になる。この方法論自体が資産である。
- **4階層モデル（マクロテーマ→波及経路→企業影響→企業アクション）。** プロダクトの原コンセプトである「トランスミッション・メカニズム」と一致する。
- **需要環境を細分化せず、次元の組み合わせで表現する方針（1.4）。** `dim_end_market` を廃止した v0.2 の判断と同じ思想であり、整合する。

### 2.2 テーマ数16は複雑すぎない

v0.2で122コードを削減した際の問題は**7次元の掛け算**であって、1次元あたりのコード数ではなかった。16は1次元に閉じており、性質が異なる。

現行の週6件×最大3テーマなら年間約900付与、16テーマで割って各56件/年。薄いが機能する水準である。

**採用を推奨する。ただしL2（サブテーマ）はMVPでは作らない。**

### 2.3 前提の問題：現在のソースではテーマがほぼ埋まらない

16テーマの語が開示タイトルに現れるかを実データで検証した（22営業日・9,372件）。

| 対象 | ヒット |
|---|---|
| 100社の開示 219件 | **全16テーマで0件** |
| 全市場 9,372件 | 最大18件（0.2%） |

マクロテーマは開示の**本文**にしか書かれない。そして本文にマクロ要因が書かれるのは、実質的に**決算説明資料と値上げリリース**の2種類である。

[本文検証](2026-09-01_disclosure_body_verification.md)で井関農機の固定資産譲渡開示を精読したが、譲渡理由は「構造改革の一環」「資産効率の向上」という内部要因であり、マクロ要因の記述はなかった。期中開示は「何をしたか」を定量値つきで正確に書く一方、「なぜか」は書かない。

**したがって、決算説明資料をPhase 1に入れるかどうかが、本分類体系を採用できるかどうかを決める。** 期中開示のみのままであれば、8テーマでも16テーマでも大半が空のまま推移する。

### 2.4 `dim_impact_mechanism` の復活は却下

v0.2で廃止した理由は2つあり、メモはいずれにも触れていない。

1. `原材料コスト上昇` は `macro_theme = 商品市況` とほぼ1対1であり、情報が重複する
2. `在庫積み増し` `設備投資` が `dim_company_action` と**同じコードで衝突**し、LLMがどちらへ入れるべきか判断できない

メモの1.5では `dim_impact_mechanism` に「原材料コスト上昇」、`dim_company_action` に「在庫積み増し」「設備投資」が並んでおり、**まさに同じ衝突が再現している**。廃止理由は解消されていないため、却下する。

### 2.5 `dim_transmission_mechanism` は Phase 2

不要だからではなく、**開示1件からは読み取れない**ためである。

「中東情勢→原油→輸入物価→原材料費→値上げ」の連鎖は、複数の開示と時間をまたいで初めて観測できる。1開示1回のLLM抽出（04§6.1）では構造的に取得できない。

これはファクトが蓄積された後に、**ファクト間の関係として**構築するものであり、抽出時に付与する属性ではない。Phase 2の最有力候補として保持する。

### 2.6 「物価・価格形成」はマクロテーマから外すことを推奨

メモ自身が未決としている論点（1.6）への回答。

「価格転嫁」は外部で起きたことではなく、**マクロ要因が企業に届く経路**である。メモ1.2の設計思想（マクロテーマ＝企業の外部で何が起きたか）に照らせば `transmission` に属する。

ここに残すと、1つの開示から `商品市況`（原因）・`価格転嫁`（経路）・`値上げ`（アクション）の3つが同時に付与され、LLMの判断が揺れる。外すと16→15になる。
