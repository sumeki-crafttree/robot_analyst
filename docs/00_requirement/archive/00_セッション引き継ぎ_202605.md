## 1. このプロジェクトの本質（00_business_idea.mdとの接続）

`00_business_idea.md` に書かれているビジネスアイデア（「あなたの会社のためのエコノミスト」）を、**鹿島建設を具体的なケースとして検証・具体化した**のが今回のセッションの成果。

ビジネスのコアバリューは「紋切りの分析ではなく、個社のビジネスに寄り添うマクロ分析」。  
→ 今回のセッションではこれを「**トランスミッション・メカニズム**」という概念で体系化した。

## 2. セッションで行った主な議論の流れ

### 2-1. 問題提起（CFO視点）
- 事業会社にエコノミスト的ポジションは存在するか？
- 大手ゼネコンでも、マクロ指標を自社事業に翻訳する機能は「予実管理などの定例業務に追われて片手間」なのが現実
- **フルタイム専任でこの機能を持つポジションは実質存在しない**という課題認識

### 2-2. 「事業経済アナリスト」の業務プロセスを設計
- インプット収集（日次/週次/月次のマクロ指標モニタリング）
- 翻訳作業（マクロ→自社セグメント別インパクトへの変換）
- アウトプット（定例レポート/シナリオ分析/アドホックアラート）
- 組織上の位置づけ（CFO直轄、事業部門との定期接点が必須）

### 2-3. 社内データ基盤の重要性
- トランスミッション分析には「自社データが分析可能な形で整備されている」ことが前提
- 多くの企業では受注データ・原価データ・開発資産データがサイロ化しており、これが最大の障壁
- 現実的アプローチ：全社DXを待たず、最小限のデータセットから始めてユースケースで正当性を示す

### 2-4. 鹿島建設を例に具体化
鹿島を選んだ理由：5セグメント（土木/建築/開発事業/国内関係会社/海外関係会社）が明確で、マクロ指標との接点が多様。

## 3. 作成済みアウトプット

### ファイル1: `鹿島建設_事業経済分析フレームワーク.xlsx`
**目的**: フレームワーク設計書。実際の報告には使わない「設計図」。

| シート | 内容 |
|--------|------|
| ①マクロデータ | 30項目のマクロ指標一覧（ソース・頻度・関連セグメント） |
| ②社内データ | 25項目の社内KPI一覧（想定ソースシステム・課題） |
| ③トランスミッション・マップ | マクロ→社内KPIの因果連鎖（タイムラグ・感応度・閾値） |
| ④アウトプット設計 | 定例/シナリオ/アドホックの3レイヤーのレポート体系 |
| ⑤年間業務カレンダー | 月次でのタスクスケジュール |

### ファイル2: `鹿島建設_マクロ環境ブリーフィング_202604.xlsx`
**目的**: 実際の月次報告資料のモックアップ。具体的な数字入り。

| シート | 内容 |
|--------|------|
| ①マクロ環境ダッシュボード | 2026年4月時点の主要指標20項目（信号機判定付き） |
| ②金利シナリオ分析 | 10Y JGB +25/50/100bpの3シナリオで開発事業・建築受注・財務コストへの影響試算 |
| ③国土強靱化シナリオ | 次期5か年計画(20兆円超)の土木セグメント受注インパクト（低/中/高シナリオ） |
| ④社内データスナップショット | セグメント別業績・官民比率・エリア別構成・開発ポートフォリオ・財務ポジション |

#### 主要な試算結果（メモ）
- **金利+50bp**: 開発事業の物件価値▲513億円、建築受注パイプライン▲1,500-2,000億円（タイムラグ9-18ヶ月）
- **国土強靱化次期5か年**: 土木受注+218億円/年（中央値）、+5.4%の押し上げ効果

## 5. 次のセッションで深めるべき論点

### 優先度高
1. **プロダクト設計の具体化**
   - 「月30万円のロボットエコノミスト」を実現するためのデータパイプライン設計
   - どのマクロデータをどのAPIで自動取得するか（e-Stat / 日銀 / Bloomberg等）
   - 顧客ごとの「翻訳ロジック」をどう実装・保守するか

2. **対象企業の拡張**
   - 鹿島以外の業種（例: 不動産デベロッパー・小売・製造）でのトランスミッション設計
   - `00_business_idea.md`に出てくるオリコム・JCB・PPIHへの適用

3. **ダッシュボード化**
   - Excelベースのレポートを、インタラクティブなダッシュボードに発展させる設計
   - 「loglassよりも優れた経営可視化」という目標に向けた要件整理

### 優先度中
4. **受注パイプラインモデルの精緻化**
   - 金利→デベロッパー投資→建築受注のタイムラグ推計の根拠を定量化
   - 過去データでバックテスト

5. **競合分析**
   - Loglass、他の経営管理SaaSとの差別化ポイントの整理

## 7. キーコンセプト用語集

| 用語 | 定義 |
|------|------|
| トランスミッション・メカニズム | マクロ指標が自社事業のどのKPIにどういう経路・タイムラグで影響するかの因果連鎖 |
| 事業経済アナリスト | マクロ指標の自社事業への翻訳をフルタイムで担う（現状ほぼ存在しない）ポジション |
| 感応度係数 | マクロ指標が1単位変化したとき、自社KPIが何単位変化するかを表す係数 |
| モニタリング閾値 | この値を超えたらシナリオ分析を発動するトリガーライン |
| キャップレート | 不動産投資の期待利回り。NOI÷物件価値。金利との連動が重要 |
