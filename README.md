## 1. プロジェクトの本質

### 1.1 コアバリュープロポジション

「あなたの会社のためのエコノミスト」を、月30万円〜の3ティア構成でAIプロダクトとして提供する。事業会社の**経営企画部・財務戦略部・IR部**を主要ターゲットに、マクロ経済指標を自社事業への定量インパクトに翻訳する月次レポート＋ダッシュボードサービス。

**v2での位置付けの明確化**: 本プロダクトは業種非依存の「マクロ→個社翻訳エンジン」であり、半導体は初期市場（ビーチヘッド）である。単一業種のTAMでは事業として小さく（§5参照）、複数業種への横展開を前提とした設計・営業体制を初期から組み込む。

### 1.2 コアコンセプト：トランスミッション・メカニズム

マクロ→自社KPI→業績への因果連鎖を「タイムラグ・感応度・閾値」で体系化する。前セッション（2026年4月）で鹿島建設をケーススタディに概念化し、2026年5月セッションで**セクター横展開の再現性**を実証した。

```
① マクロ指標         → ② 個社翻訳ロジック    → ③ 個社業績インパクト
- 金利                  - 事業セグメント別       - 売上影響（億円）
- 為替                  - 顧客産業別             - 営業利益影響（%）
- 資材価格              - 感応度係数             - 受注高影響
- 労務単価              - タイムラグ仮定         - シナリオ別
- Hyperscaler CapEx     - 転嫁率仮定             - 12-24ヶ月先まで
- メモリ価格
```

### 1.3 差別化の三本柱

「月次の継続性」「個社への翻訳」「社内データとの接続」を一本化する。既存の代替案（セルサイドアナリスト、Bloomberg/FactSet、シンクタンク、コンサルファーム、フルタイム経済アナリスト雇用）のいずれも、この3点を同時に満たしていない。

## 2. 経営企画部の実態とペイン

本プロダクトのProduct-Market Fitは、事業会社の経営企画部が抱える**構造的な時間貧困**と、それに起因する**マクロ翻訳機能の慢性的欠落**にある。この章は、CFO経験者として実感してきた実態と、それに対するロボエコノミストの解決経路を整理する。

### 2.1 業務範囲の広さと時間予算のリアリティ

経営企画部は、外から見ると「経営の頭脳」に見えるが、実務の中身は**定型業務と社内調整で埋め尽くされている**というのが実態である。マクロ経済の継続的な翻訳を専任で担う人的・時間的余力は、大手企業でも例外なく存在しない。

**年間業務カレンダー（3月決算・上場企業の典型）**

| 時期 | 主な業務 |
|-----|---------|
| 4月 | 新年度予算スタート、通期業績見通し公表準備 |
| 5月 | 本決算発表、決算説明会資料作成、決算短信・有価証券報告書 |
| 6月 | 株主総会対応、統合報告書ドラフト |
| 7月 | Q1業績集計、予実分析 |
| 8月 | Q1決算発表、中間期業績予想の初期見直し |
| 9月 | 中間期予算改定、中経の進捗レビュー |
| 10月 | 中期経営計画の年次見直し検討開始 |
| 11月 | Q2決算発表、来期予算策定キックオフ |
| 12-1月 | 翌年度予算の事業部積み上げ |
| 2月 | Q3決算発表、予算最終調整 |
| 3月 | 予算最終確定、来期見通し、中経再改定 |

このカレンダーは「常時走る」もので、期の切れ目でも隙間がない。

**これに常時走る非定型業務**

- 取締役会・経営会議の資料作成（月2回、1回あたりA4 30-50頁級）
- IR対応（機関投資家個別ミーティング、四半期説明会、アナリスト訪問対応）
- M&A実行時の受け皿（デューデリ、スキーム設計、統合実務）
- 事業ポートフォリオ管理
- サステナビリティ関連の統合報告書対応
- 各事業部との定期連絡・調整
- 経営指標のモニタリング・KPI管理
- 中期経営計画の随時見直し

**人員規模の現実**

- 大手（売上1兆円級）でも経営企画部は10-30人規模、多くは事業部担当・戦略担当・海外担当・M&A担当と役割分担
- 中堅（売上300-1,000億円）だと3-5人しかいないことが多い
- 「マクロ担当」というポジションを設置できるのは、売上規模5,000億円以上の企業のごく一部
- マクロ担当が置かれていても、実務の中身は日銀レポート・シンクタンク見通しの要約整理に留まり、自社事業への翻訳までやり切れているケースは稀
- 経済学バックグラウンドを持つ人材は事業会社に極めて少ない。主流は事業部・営業・財務出身で、マクロ翻訳の専門性は担当者交代のたびにゼロリセットされる

### 2.2 マクロ翻訳が「不在」または「片手間」になる構造的4要因

マクロ翻訳機能が育たない理由は、単なる人員不足ではなく、**組織構造・キャリア設計・ツール環境の複合的欠陥**である。

第一に**時間予算の枯渇**。上述の年間カレンダーで見た通り、経企担当者の可処分時間は常に予算策定・決算対応・IR資料に食われている。マクロ翻訳のような「重要だが緊急でない業務」は、割り込みの緊急業務に常に押し出される。

第二に**専門人材の不足と流動性**。事業会社の経企部にマクロ経済の専門家を継続的にアサインできる余裕はない。稀にそのような人材がいても、3-5年で異動・退職し、知見が継承されない。属人化と喪失の繰り返しになる。

第三に**ツール・データセットの断片化**。マクロデータ（e-Stat、日銀、Bloomberg）と社内データ（受注、原価、在庫）が別々のシステムに置かれ、両者を結び付ける翻訳レイヤーが存在しない。担当者はマクロ指標を手作業でExcelに転記し、事業部データを別のExcelから拾い、感応度係数を勘で埋める作業を毎回ゼロから繰り返している。

第四に**評価・報酬制度上の位置付けの弱さ**。マクロ翻訳の成果は「予測精度」で数字にしにくく、経企担当者のKPIに組み込まれない。翻訳作業に時間を投下しても評価に直結しないため、優先順位が下がる。

### 2.3 具体的なペイン・シナリオ（6ケース）

抽象論だけでは伝わりにくいので、実際に経営企画部で起きているシチュエーションを6つに整理する。ロボエコノミスト導入で解決されるべきシーンでもある。

**Scenario A — 経営会議での即答不能**

役員会議で「BOJが利上げしたけど、我々の業績への影響はどれくらい？」と問われる。経企担当は翌週までに試算を出すと約束するが、実際には社内データを掻き集めるだけで数日、事業部への感応度分解までは時間切れで諦める。結局「注視します」「動向を見守ります」という無内容な社内メモが提出され、経営会議の議論は前に進まない。この会議を月2回、経営指標が動くたびに繰り返している。CFOの側から見ると「経企部は数字を出せない部門」という認識が徐々に固定化する。

**Scenario B — 中期経営計画のマクロ前提の形骸化**

3年後・5年後の売上計画を立てる際、マクロ前提は定型的（GDP成長率2%、インフレ2%、USD/JPY 145円等）で置かれる。各事業部が積み上げた計画数字と、マクロシナリオの整合性が取れていないまま中計発表。1年後にマクロが想定と大きく乖離しても、事業部計画への影響を即座に翻訳できないため、中計未達の原因分析で「マクロ環境の悪化が主因」と抽象的に片付けざるを得ない。IR面では投資家の不信を招き、株価バリュエーションに徐々に反映される。

**Scenario C — 投資家質問への即答不能**

決算説明会で機関投資家から「金利+50bpの御社業績への影響は？」と質問される。CFO/IR部長が即答できず、「後日ご説明する」となる。内部で試算していないため、抽象論で回答する場面が繰り返される。投資家サイドは「この会社は自社の感応度を数値で管理していない」という印象を持ち、アナリストレポートで指摘され、株価バリュエーションに徐々に反映される。上場企業においては、これは中期的な資本コストの上昇を意味する。

**Scenario D — セルサイドアナリスト対峙の弱さ**

アナリストが自社について書いたレポートを受け取ると、そこにあるマクロ前提と自社の内部前提が異なる。どちらが正しいかを判定するために毎回時間を使うが、そもそも自社側の「一次的な見立て」が体系化されていないため、比較の土台がない。結果、アナリストレポートに反論できず、彼らの解釈がマーケットの標準見解になる。自社の情報発信力・ナラティブコントロール力が弱いまま推移し、株主総会や機関投資家説明会でも受け身の対応が続く。

**Scenario E — 予算策定の科学化の限界**

年度予算策定時、事業部が自主積み上げてきた売上計画に対し、経企が「マクロシナリオを踏まえた妥当性」を検証しようとしても、既存のツール・データセットでは事業部別の感応度分解ができない。結局、事業部の言い分を「大枠妥当」として通す。翌年、マクロ環境が動いて予算未達になった時、事後分析で「マクロ影響」「事業部要因」を分離できないため、責任の所在が曖昧になり、次年度の予算策定精度も向上しない。「毎年同じ議論を繰り返している」という慢性的な不全感が経企部全体に蓄積する。

**Scenario F — キャリアパスの断絶と属人化リスク**

経営企画部の主流は事業部・営業・財務経験者で、マクロを深掘りする専門性は、担当者が変わるたびにゼロリセットされる。「マクロ翻訳の型」が組織内に蓄積されず、退職・異動で属人的知見が失われる。結果、マクロ変動局面のたびに「同じ試算」を何度もやり直す非効率が続く。若手にとっても学べる型がないため、事業経済アナリスト的な人材が育たない。

### 2.4 ロボエコノミストの解決経路 — 機能とアウトカムの2軸整理

上記のペインに対する解決策を、「提供する機能（What we deliver）」と「顧客が得る変化（What changes for the customer）」の2段階で整理する。

**機能：What we deliver**

- **月次マクロダッシュボード**：20-40指標を信号機判定付きで配信。経企担当は「読んで社内展開する」だけでよい状態にする
- **マクロ→個社感応度マトリクス**：「金利+50bp→自社営業益▲3〜5%（9-18ヶ月遅行）」まで定量化された行列を毎月更新
- **3シナリオ分析**：ベース／弱気／強気で12-24ヶ月先の業績インパクトを試算
- **感応度の裏付けドキュメント**：各セルの推計根拠・過去事例・データソースを添付し、社内説明可能な状態で配信
- **経営会議用サマリー資料**：経営会議・取締役会にそのまま出せる1-2枚のCXOブリーフ（Premium以上）
- **業績予想修正のギャップ診断**：会社業績予想と我々のマクロシナリオ想定の乖離を診断（Premium以上）
- **速報アラート**：マクロ指標が閾値を超えたら、経企部にアラート配信（Enterprise）
- **バックテスト付き年次診断**：過去の感応度モデルを実績に対して検証、精度を継続的に証明（Enterprise）

**アウトカム：What changes for the customer**

第一に**時間の返還**。毎回ゼロから試算する数十時間を、月1-2時間の「レポートを読む＋社内配信」に圧縮。経企部は本来業務（予実管理・中計・予算策定）にリソースを集中できる。特に決算前後・予算策定期・中経策定期のピーク期間で余裕が生まれる。

第二に**即答能力の付与**。経営会議・取締役会・投資家質問への即答が可能に。経企部の発言の権威が上がり、CFOへの説明品質が向上する。Scenario Aで見た「注視します」のメモは、「金利+50bpは弊社営業益に▲3.5%、9-18ヶ月遅行で顕在化。次期中計の前提を要見直し」という定量的な提言に変わる。

第三に**中経・予算の科学化**。予算前提として3シナリオを使い、事業部積み上げとの整合を毎期突合。中経未達の事後分析で「マクロ要因X%、内部要因Y%」と分解可能になり、Scenario Bで見た「マクロが主因」の抽象的な言い訳が消える。次年度の予算精度向上に直結する。

第四に**IR価値の向上**。感応度マトリクスの一部を投資家説明会で公開することで、「この会社は自社の感応度を数値で管理している」という信頼を投資家に与えられる。ROEプレミアム的な効果を狙える。Scenario CとDで見たアナリスト対峙の弱さも、自社の一次的な見立てを持って対比できる状態になる。

第五に**組織学習の加速と属人化解消**。ロボエコノミストが配信する月次レポートそのものが、経企担当者の教育材料になる。事業経済アナリスト的な人材が組織内で育つ土壌ができる。Scenario Fの担当者交代時のゼロリセット問題も、レポートというドキュメント化された「型」があるため、知見が継承される。

第六に**費用対効果の明確化**。フルタイム経済アナリスト雇用（年2,500-3,500万円、そのうえ採用そのものが困難）が不要になる。Standard 360万円/年で「経済アナリスト1人相当の月次アウトプット」を代替でき、Premium 960万円/年で「上級アナリスト1人相当」、Enterprise 2,400万円/年で「アナリスト＋研究員2人分の常時サポート」まで代替可能。

### 2.5 なぜ今なのか（Why now）

このプロダクトの需要は歴史的に見て**2026年時点が最も高い**局面にある。理由は5つ。

第一に**金利地殻変動**。10Y JGBが約30年ぶりの2%台に到達（前月号1.58%→本月号2.47%）。マクロ変数の業績影響が「無視できない大きさ」に戻った。金利をノイズとして扱えた過去10年と質的に異なる時代。

第二に**AI設備投資バブル**。半導体・電機セクターで、マクロ変動（Hyperscaler CapExの変化）の業績影響が四半期ごとに大幅に変わる時代。月次でも間に合わないため、経企部の時間不足がさらに顕在化。

第三に**地政学リスクの常態化**。米中対立、台湾情勢、中東情勢が業績前提を随時揺らす。従来「一過性リスク」で処理されていた地政学が、常時モニタリングが必要な変数に格上げされた。

第四に**サステナビリティ開示の必須化**。2023年3月期から有報でサステナビリティ開示が必須。カーボンプライシング等の新マクロ変数を経企が扱う必要が出てきたが、既存人員で吸収できない業務量。

第五に**人手不足の深刻化**。経営企画への追加人員投入が経費増議論で通りにくい。中途採用市場でもマクロ経済人材の獲得競争は激化。**外注機能・SaaS機能への需要が構造的に高まっている**。

これらのトレンドが2026年時点で同時進行しており、事業会社CFO・経営企画部が「マクロ翻訳機能をどう補うか」を真剣に議論せざるを得ない局面。ロボエコノミストは、この構造的ニーズに対する自然な解として位置付けられる。

## 4. 検討したコア論点

### 4.1 既存アナリストレポート市場のギャップ検証

「金利変動や材料費変動が上場個社の決算に与える影響を評価したアナリストレポートは既に存在するか？」という問いに対して、公開情報を層別調査した結論：

- **セルサイド証券アナリスト（野村・大和・みずほ・SMBC日興・GS/MS/JPM等）** — 個社カバーはあるが、頻度は決算前後集中で、視点は投資家向け、内部データなし。
- **シンクタンク（NRI・大和総研・みずほ産業調査・三菱総研）** — 業界マクロは精緻だが個社まで落ちない。
- **業界研究所（RICE建設経済研究所・不動産経済研究所・ARES）** — 業界統計に強いが個社解像度なし。RICEの「建設経済モデル」は無料公開だが業界全体レベル。
- **格付機関（R&I・JCR）** — 格付理由文に定性感応度記述あり、詳細は契約者限定。
- **政府系（DBJ設備投資計画調査・国土強靱化計画・首相官邸資料）** — 業種横断の投資動向は把握可能、個社への翻訳なし。
- **企業自身のIR資料** — 定性コメントはあるが定量感応度（"+50bpで▲X億円"）は開示なし。
- **メディア・業界紙** — 記述レベルの解説はあるが定量モデルではない。

**結論**: 「個社×複数マクロ×タイムラグつき定量シナリオ×月次更新」を埋める公開ソースは存在しない。ここがロボエコノミストの存在余地。

### 4.2 セクター拡張の実証

同じ8シートフォーマットで**建設5社**と**半導体5社**の2セクターレポートを作成し、業種間の性質の差を鮮明にした。

| 観点 | 建設業 | 半導体業 |
|------|--------|----------|
| 典型サイクル長 | 9-18ヶ月（受注→売上計上） | 3-6ヶ月（在庫サイクル） |
| 顧客産業の多様性 | 国内中心、限定的 | 自動車・PC・スマホ・DC・産業 全方位 |
| マクロ感応度の振れ幅 | ±10〜15% | ±30〜50% |
| 為替・地政学の重要度 | 限定的 | 極めて高い（米中・台湾） |
| 転嫁率・物価スライド | 70%程度、契約条項あり | メモリは即時自動、装置はノード進化次第 |
| 推奨レポート頻度 | 月次で十分 | 月次+週次推奨、Enterpriseは随時 |
| 推奨ティア | Standard/Premium中心 | Premium/Enterprise中心 |

### 4.3 半導体経営企画部の情報ニーズマップ

半導体産業は「マクロ翻訳の難易度と業績インパクトが建設の3-5倍」という特殊性を持ち、経営企画部の情報ニーズは5層構造：

1. **業界特有の需給データ（週次〜月次）** — WSTS、SEMI B/B比、TrendForceのDRAM/NANDスポット価格・コントラクト価格、Gartner/IDC/Omdia
2. **顧客産業のドライバー（四半期〜月次）** — Hyperscaler CapEx（Amazon/Google/MS/Meta）、スマホ・PC出荷、自動車生産、AI関連需要
3. **競合・サプライチェーン（決算カレンダー密度）** — TSMC・Samsung・Intel・SK Hynix・Micron・ASML・AMAT・KLA・Lamの決算とガイダンス
4. **マクロと地政学** — GDP・PMI・為替（USD/JPY, USD/KRW, USD/TWDのペア）、米中輸出規制、CHIPS Act、ラピダス
5. **自社オペレーション** — 工場別・プロセスノード別稼働率、歩留まり、製品ミックス売価、在庫回転日数

## 5. 市場サイジング（TAM/SAM/SOM）【v2全面改訂】

### 5.0 v1からの重要な訂正

v1の§5では「半導体TAM約55億円/年・SAM約51億円/年」と記載していたが、これは**月額ARPAから年額を算出する際の桁誤りによる10倍の過大計上**であった（例: 15社×60万円/月×12ヶ月=1.08億円/年であり、10.8億円ではない）。SOMの数値（Y1 1,800万円〜Y5 2.52億円）は正しく計算されており、v1内でTAMとSOMが不整合だったこと自体が誤りの証跡である。本v2では全数値を訂正のうえ、市場の捉え方自体を「半導体単独」から「業種横展開を前提とした全産業ベース」に改める。

### 5.3 SAM（Serviceable Available Market）

**半導体SAM（当面の営業対象）**: 売上1,000億円以上×経営企画部明確×マクロ感応度大の絞込みで**約75社・約5.1億円/年**。半導体は中堅以上の各社に経営企画機能が必ずあるため、TAMに対するSAM比率が高い。

**全産業SAM（Y3以降の営業対象）**: 同条件の絞込みで**約450社・約22億円/年**(全産業TAMの約65%)。業種によって経企機能の充実度・外注受容度が異なるため、業種別ケーススタディの進捗に応じて改定する。

業種横展開を織り込んだ改訂軌道。Y1-Y2は半導体特化、Y3から第2業種（自動車部品を想定、§6参照）に参入する。

| Year 2（本格展開） | 8社 | 半導体8 | 60万円 | 5,760万円 |
| Year 3（第2業種参入） | 16社 | 半導体12＋自動車部品4 | 60万円 | 1.15億円 |

### 5.5 サイジングの前提と限界（正直な注記）

- 対象社数・ARPAはトップダウン推計であり、ボトムアップの支払意欲検証（PoC価格受容）はY1の最重要検証項目
- チャーン率・CAC・営業サイクル長（エンタープライズ向け年360万円超の商材は通常6-18ヶ月）は未検証。SOM軌道はこれらの仮定に強く依存する
- データライセンス費用（Bloomberg・TrendForce等の再配布権）はCOGSに直接影響する未解決論点（§9.4参照）

## 6. 業種横展開戦略【v2新設】

### 6.1 展開先選定の6基準

半導体の次に攻める業種は、以下の6基準でスコアリングして決める。

1. **マクロ感応度の大きさ** — 変数1単位の変化が営業益を何%動かすか。大きいほどペインが強い
2. **対象社数の厚み** — 売上300億円以上で経企機能を持つ企業の数。市場の広さ
3. **ペインの鮮度・支払意欲** — 直近のマクロ変動で「翻訳できない苦しみ」を実体験しているか
4. **データ入手性** — 感応度モデル構築に必要な業界データが公開・安価に取れるか
5. **既存アセットの再利用性** — 建設・半導体で構築済みの翻訳ロジック・顧客産業ドライバーを流用できるか
6. **社内代替の不在** — 自前エコノミスト・調査部門を持たないか（持つ業種は不在仮説が崩れる）

### 6.2 業種別スコアリング（5点満点×6基準）

| 業種 | 感応度 | 社数 | ペイン鮮度 | データ | 再利用性 | 代替不在 | 合計 | 順位 |
|------|-------|------|-----------|--------|---------|---------|------|------|
| 自動車・自動車部品 | 5 | 5 | 5 | 4 | 4 | 4 | **27** | **1** |
| 化学・素材 | 4 | 5 | 4 | 4 | 4 | 4 | **25** | **2** |
| 食品・飲料 | 4 | 4 | 5 | 4 | 3 | 5 | **25** | **2** |
| 不動産・REIT | 5 | 3 | 4 | 4 | 5 | 3 | **24** | **4** |
| 機械・産業機械 | 4 | 4 | 3 | 3 | 4 | 4 | **22** | **5** |
| 小売・外食 | 3 | 4 | 4 | 3 | 2 | 5 | **21** | **6** |
| 海運・物流 | 5 | 2 | 3 | 4 | 2 | 3 | **19** | **7** |
| 電力・エネルギー | 4 | 2 | 3 | 3 | 2 | 2 | **16** | **8** |

### 6.3 上位業種の詳細論拠

**第1位: 自動車・自動車部品（特にTier1/Tier2中堅）**

- 為替±1円で営業益が数十億円動くOEM、関税・EV政策・原材料（鋼材・樹脂・レアメタル）と多変数のマクロ感応。感応度の「桁」が半導体に匹敵する
- OEM各社は決算説明で為替感応度を自ら開示する文化があり、**買い手が感応度という概念に教育済み**。売り込み時の概念説明コストが低い
- 一方、部品Tier1/Tier2の中堅（売上500-3,000億円級）は経企3-10名でエコノミスト不在。ペイン構造がフジミ・ソシオネクストと相似形であり、シード3社で作る営業プレイブックがそのまま流用できる
- 半導体レポートで構築済みの「自動車生産台数」ドライバー、車載半導体の需給ロジックを再利用可能。既存2セクターとのシナジーが最大
- リスク: OEM超大手は社内調査機能あり。狙いは部品中堅に定める

**第2位タイ: 化学・素材**

- ナフサ・原油・為替・中国需給という明快な変数構造。「原料価格スプレッド」は感応度モデルと最も相性が良い題材で、モデルの説得力を示しやすい
- 上場社数が厚く（100社超）、半導体材料（信越化学・レゾナック・東京応化等）と対象企業が重複するため、営業導線が既に存在する
- 総合化学大手は調査機能を持つが、専業中堅（売上300-2,000億円）は不在

**第2位タイ: 食品・飲料**

- 2022-2024年の輸入インフレで「原料高をいつ・どれだけ価格転嫁できるか」が経営アジェンダの最上位に来た業種。ペインの鮮度・実体験度は全業種で最高レベル
- 自前エコノミストを持つ企業がほぼ皆無で、代替不在スコアは満点
- 弱み: ARPA上限が低め（Standard中心）、半導体との翻訳ロジック共通性が低く追加構築コストがかかる。「第3〜4業種」としての位置付けが適切

**第4位: 不動産・REIT**

- 金利感応度は全業種最大級で、建設レポートの翻訳ロジック（キャップレート・調達コスト・資材/労務）をほぼそのまま再利用できる
- 弱み: 大手デベは市場調査部門を持ち、REITは運用会社にアナリストがいるため、代替不在仮説がやや弱い。中堅デベ・不動産サービスに絞る

### 6.4 非推奨業種（明示しておく）

- **金融（銀行・保険・証券）・総合商社**: 自前のエコノミスト・調査部を保有しており「マクロ翻訳機能の不在」という根本仮説が成立しない。逆に**販売パートナー・データ提供元**としての連携先候補（§8.3参照）
- **電力・ガス・通信**: 規制産業で業績感応度が料金制度に依存し、翻訳の付加価値が出にくい。意思決定サイクルも長い

### 6.5 展開ロードマップへの反映

- Y1-Y2: 半導体に集中（プレイブック完成・バックテストによる精度証明を最優先）
- Y2後半: 自動車部品のケーススタディレポート作成（既存8シートフォーマット適用、Tier1中堅5社）
- Y3: 自動車部品で商用参入。化学は半導体材料顧客からの紹介ベースで先行PoC
- Y4以降: 食品・飲料、不動産中堅へ拡張。業種別テンプレートの標準化により、新業種立ち上げコストを逓減させる

## 9. 追加データソース候補

### 9.1 有価証券報告書統合

EDINET（金融庁）で有報XBRLを無料公開しているため、実装障壁は低い。付加価値は4層：

- **感応度計算の精緻化** — セグメント情報・地域別売上・主要顧客欄から「概算」を「実測」に置換。ソニーGの北米売上比率33.4%、為替ヘッジ比率など。
- **経営陣リスク認識との整合性ダイアグノスティック** — 「事業等のリスク」章と自社の翻訳ロジックの突合、5年時系列変化の追跡（気候変動リスクの追加、米中対立記述の詳細化など）
- **MD&A整合性チェック** — 経営者コメントと感応度モデルの照合による継続バックテスト
- **サステナビリティ情報の統合** — GHG排出量・TCFD開示から新マクロ変数（カーボンプライシング、気候リスク）へ

### 9.2 適時開示のリアルタイム反映

TDnetから機械取得可能。Enterpriseの決定的差別化要素：

- 業績予想修正の自動反映＋ギャップ診断
- M&A・業務提携の即時織込み
- 設備投資計画のトラッキング（TSMC熊本第2工場発表→TEL受注インパクト更新）
- 閾値アラート（想定シナリオを超える開示で自動配信）
- 決算発表後24時間以内の速報レポート

### 9.3 同業BS動向の構造化（独自性の高い付加機能）

同業横串で見たときに立ち上がる「業界の資本フローの構造」を可視化。5層の情報価値：

- **設備投資サイクル判定** — 有形固定資産＋建設仮勘定（CIP）の業界横串。TSMC/Samsung/Intel/Micronの4社CapExを積み上げ→装置受注3-6四半期先読み
- **在庫サイクル異常検知** — メモリ3社（キオクシア・Micron・SK Hynix）の棚卸資産回転日数からNAND/DRAM価格反転を3-6ヶ月前に警告
- **運転資本の質** — DSO推移、前受金増減、支払サイト変化
- **M&A・出資動向** — のれん急増、投資有価証券変化から業界内資本参加を検出
- **業界の財務健全度** — 有利子負債/EBITDA分布、自己資本比率レンジ

これはPremium・EnterpriseのARPUに月+30-50万円の上乗せ余地。「業界の資本フローが見える」ことは中期計画策定・投資意思決定・M&A判断すべてで使える汎用性を持つ。

### 9.4 データライセンスの未解決論点【v2追記】

Bloomberg・TrendForce・Gartner等の商用データを**顧客向けレポートに再配布する行為はライセンス契約上の制約が大きい**（再配布ライセンスは端末契約と別建てで高額）。公開・官公庁データ（e-Stat、日銀、財務省、EDINET、TDnet、WSTS公表値）を一次基盤とし、商用データは「参照・自社分析への入力」に留める設計を初期から徹底する。COGSとリーガルリスクの両面で、プロダクト設計の前提条件として§11のロードマップに組み込む。

|------|------|
